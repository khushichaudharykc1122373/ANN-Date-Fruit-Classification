# 🍇 Date Fruit Classification using ANN

## 📌 Project Overview

This project uses an **Artificial Neural Network (ANN)** to classify different varieties of date fruits based on their physical and morphological features.

The dataset is preprocessed and scaled before being used to train the ANN classification model. The model is then evaluated using various classification metrics and visualization techniques.

## 📊 Dataset

The project uses the **Date Fruit Dataset**, which contains morphological and physical features of different date fruit varieties.

The target variable represents the **date fruit variety/class**.

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn
* TensorFlow / Keras
* Jupyter Notebook

## 🔄 Project Workflow

1. Load the Date Fruit dataset
2. Perform data exploration and analysis
3. Handle data preprocessing
4. Encode categorical target labels
5. Split the dataset into training and testing sets
6. Apply feature scaling
7. Build the ANN classification model
8. Train the model
9. Evaluate model performance

## 🧠 ANN Model

The Artificial Neural Network consists of:

* Input layer
* Hidden layers with activation functions
* Output layer for multi-class classification

The model is trained using the training dataset and evaluated on unseen test data.

## 📈 Model Evaluation

The model performance is evaluated using:

* Accuracy


```bash

```

Run the notebook cells sequentially to train and evaluate the ANN model.

The main objective of this project is to demonstrate how an **Artificial Neural Network can be used for multi-class classification of date fruit varieties** using numerical features.
